One funny passive-aggressive note that a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

## The note

> The ice maker made 47 cubes today. You used none. It has started making them out of spite, and frankly, so have I.

## How it works

`main.py` prints the note to stdout and writes the exact same text to `/output/entry.txt` (and to `$ENTRY_OUT` when the harness provides one). The entry is a single line of 114 characters, inside the 1–200 character gate.
